# eFlow Mobile v1 redesign

Product: **eFlow Mobile — Work, Updates & Approvals**.

Contract: **shared backend contracts and business-rule parity, intentional mobile feature selection, and native mobile UX**. Android and iOS are equal acceptance targets with independent evidence. eFlow Web remains the authority for branding, terminology and backend behavior. monday.com is a usability reference only; no third-party brand/assets are reused.

The user accepted M0 and authorized M1 on 4 November 2026, Asia/Singapore. M1 introduces the native navigation shell and shared design system. The user then authorized M2 and deferred their M1 personal test.
